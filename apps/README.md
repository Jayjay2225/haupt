# apps/

- `report/` (entsteht mit Prompt 5): Berichtsgenerator – HTML-Template → PDF via Playwright, Eingabe = `CalcResult` + Eligibility-Ergebnis + Kundendaten.
- `web/` (entsteht mit Prompt 6): Next.js-Website (App Router) mit Rechner-Funnel, programmatischen Versicherer-Seiten und Admin-Bereich.

Beide Apps werden bewusst erst mit ihren Prompts angelegt: Prompt 5 braucht `brand/` (Logo, Farben), Prompt 6 die Entscheidungen zu Marke und Geschäftsmodell A/B/C (siehe `docs/STATUS.md`).
